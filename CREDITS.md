# Credits

This extension's math and test data were pinned down against the
following external references.

- **domerama.com** — Published chord factor, strut count, and hub count
  data used as test reference data for this extension's automated test
  suite. See `reference/domerama_chord_factors.md` for the collected
  tables, source URLs, and documented discrepancies found while checking
  the site's data against independently computed geometry.
- **David Kruschke**, *Dome Cookbook of Geodesic Geometry* (1972) — the
  original published source for the Kruschke flat-base construction
  method implemented here for 3V/4V (and extended to 5V/6V in this
  extension).
- **acidome.com** — dome calculator referenced while working out
  construction details.
- **The geodesichelp Google group** (discussions involving Gerry Toomey) —
  reference discussions used while working out construction details.
